# MariaSM — A little beauty in the everyday

The official MariaSM English journal: shopping, beauty, personal style, daily life and travel.

Website: https://mariashoppingmania.github.io/mariasm-daily-life/

## Complete source project

Download and extract `mariasm-site.zip`. It contains all editable source files, photographs, video metadata, eight generated HTML pages, source credits, validation scripts and detailed editing instructions. No credentials or external dependencies are needed to build it.

The workflow in `.github/workflows/pages.yml` extracts the source archive, generates the static pages, checks local links and publishes only the website files to GitHub Pages. To publish an update, replace the archive with the updated project, keeping its top-level `mariasm-site` folder. The workflow runs automatically on changes to `main`.

The website features 40 distinct videos, the latest 10 uploads, a 10-video Most Watched ranking, and owner-authorised photographs. Video selections and statistics are a dated editorial snapshot, not an automatically refreshed feed. Sources and dates are documented inside the archive and on the website.

MariaSM imagery is used for the owner's official project. No general open-source licence is granted for the photographs, channel branding or other third-party assets. See the source project's `SOURCES.md` for provenance.
